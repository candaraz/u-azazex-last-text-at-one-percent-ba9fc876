Entry for the make.fun bounty "Last Text at One Percent": one final text
message from a dying phone at one percent battery — a specific, petty,
years-old confession it chooses to spend its last charge on.

The program (`main.ts`, Node 22, standard library only) reads `entry.txt`
from its own directory and writes it, byte for byte, to `entry.txt` inside
`MAKEFUN_OUTPUT_DIR`.
